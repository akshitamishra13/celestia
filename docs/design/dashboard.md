# Dashboard design direction

The initial dashboard uses a warm, calm visual system:

- warm cream and ivory surfaces form most of the interface;
- burnt orange is reserved for primary actions and active states;
- saffron highlights support icons and subtle celestial details;
- deep warm plum anchors the sidebar and provides contrast;
- serif display headings add character while system sans-serif text keeps the UI readable.

The desktop layout uses a persistent sidebar, compact top bar, welcome panel, two primary feature cards, an astrology snapshot, and recent reports. On smaller screens the sidebar becomes a drawer and content stacks into a single column.

Dashboard values are static prototype content until authentication, profiles, and astrology APIs are connected.
