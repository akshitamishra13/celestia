# AstroLive

AstroLive is being developed incrementally as a web application for authenticated Kundli, compatibility, and report experiences.

## Workspace structure

```text
apps/
  web/       Next.js frontend
  api/       FastAPI backend
docs/        Architecture, UI, and implementation decisions
```

The first product phase covers authentication and the dashboard. Application scaffolding and dependencies will be added only when that phase begins.
