# AstroLive Web

This directory contains the Next.js and TypeScript frontend.

Planned source areas:

```text
src/
  app/          Routes and layouts
  components/   Shared and feature components
  features/     Domain-specific frontend modules
  lib/          API client, utilities, and configuration
  styles/       Global styles and design tokens
  types/        Shared frontend types
```

The responsive dashboard shell is the first implemented frontend checkpoint. Authentication screens and backend integration follow in the next checkpoint.

## Local development

```bash
npm install
npm run dev
```
